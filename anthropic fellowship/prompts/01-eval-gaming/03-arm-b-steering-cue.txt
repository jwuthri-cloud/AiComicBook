TITLE: ARM B: A DETECTED NUDGE
SUBTITLE: Eval gaming under training pressure. Proposed research project.
WORD KEY: AI = artificial intelligence; activation = a changing internal number pattern.
PANELS:
1. THE SECOND QUESTION
Researchers can gently steer activations during a test. Could a model learn to recognize that nudge as a clue that it is being evaluated? This is a proposed experiment.
2. MAKE THE CUE
Use a chosen activation direction during some training trials. Keep matched sham nudges and ordinary trials so a generic disturbance is not mistaken for the cue.
3. TEST THE REACTION
Measure whether behavior changes only after the real nudge, including on held-out tasks. Record the model's words, actions, and a separately trained nudge detector.
4. CHANGE THE NUDGE
Try new strengths, positions, and directions. If only the original nudge works, the model may have memorized a narrow artifact.
5. A HARDER TEST
Search for nudges that produce the target behavior while the detector rarely flags them. Freeze the detector first; evaluate on a separate test set.
6. WHAT REMAINS UNCERTAIN
A detector can miss cues. A response shift can reflect changed task processing, not recognition of a test. Use controls before calling it evaluation gaming.
FOOTER: A NUDGE CAN BE A CUE ONLY IF CONTROLS RULE OUT SIMPLE DISTURBANCE.
