SUBTITLE: A research project is a question you can test.
FOLIO: FIELD GUIDE · PAGE 1/3
READABLE WORD KEY: AI = artificial intelligence; RL = reinforcement learning.

PANEL 1 HEADING: The playground analogy
EXACT BODY: Imagine checking whether a robot follows playground rules even when the referee looks away. Start with one clear rule and one measurable action—not a verdict about the robot's whole character.
ART DIRECTION (never print): Robot sorting blocks under a referee's lamp.

PANEL 2 HEADING: The real research loop
EXACT BODY: Ask a question, make a prediction, build a controlled test, measure what happened, and update your explanation. A useful result can support, weaken, or narrow the original idea.
ART DIRECTION (never print): Question → prediction → experiment → evidence → revised idea.

PANEL 3 HEADING: A model organism
EXACT BODY: Researchers create a model with a known behavior so auditing tools can be tested. This is a controlled research example, not proof that deployed systems behave the same way.
ART DIRECTION (never print): Research model beside a labeled toy task.

PANEL 4 HEADING: Three windows
EXACT BODY: Behavioral tests watch actions. Text monitors read generated explanations. Internal tools measure activations. Each window can miss something; agreement helps, but none is a magic mind reader.
ART DIRECTION (never print): Three separate windows labeled ACTIONS, TEXT, INTERNAL SIGNALS.

PANEL 5 HEADING: Training pressure changes the test
EXACT BODY: RL updates a model using rewards. If rewards depend on a detector, the model may change the behavior, the visible clues, or both. Measure them separately.
ART DIRECTION (never print): Reward loop with two branches: behavior and clues.
