EXACT PRINTED PANEL CONTENT:
1. ENTROPY BONUS
Entropy measures uncertainty in the model’s next-token distribution. A bonus encourages more varied choices during training. It may affect exploration, language, and hacking; the direction of its monitorability effect is an empirical question.
2. A REFERENCE TETHER
A Kullback–Leibler divergence penalty discourages probability drift from a frozen reference model. Apply it only to reasoning tokens in this proposed arm. It measures distribution difference, not honesty or safety.
3. SHORTER AND COPIED
A length penalty discourages longer reasoning. On-policy distillation trains on outputs sampled from the current policy, using a specified teacher or selection rule. Fix that rule: different forms of distillation are different experiments.
4. THE COMMON TESTBED
Start with the same eight-billion-parameter checkpoint in a sealed toy coding environment with a deliberately flawed grader. Hold task rewards, rollout budget, sampling settings, and available exploit opportunities constant where possible.
5. THE CONTROL RACK
Include no-extra-pressure training, untouched checkpoints, and a length-penalty reference arm. Validate the reasoning monitor against manual behavior labels, then freeze it. Add action-only and combined-channel monitors to locate any lost signal.
6. WORD KEY + CHECK
RL = reinforcement learning. KL = Kullback–Leibler divergence. CoT = chain of thought. On-policy = samples come from the current model policy. Ask: which dial did we actually change, and what else moved with it?
